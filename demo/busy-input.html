DÉMO · MESSAGES PENDANT UN TOUR

Que faire quand le modèle travaille déjà ?

Un agent conversationnel est en train de traiter une question. Tu envoies un nouveau message : doit-il attendre, interrompre, modifier le travail en cours ou l'arrêter ?

Mode d'emploi : choisis une stratégie, écris un message dans la boîte, puis observe la simulation. La page fonctionne entièrement dans ton navigateur : aucun backend, aucune base de données et aucun message n'est envoyé.

CHANGER LA DIRECTION

Interruption

Le nouveau message redirige le tour actuel. Le modèle arrête sa génération dès qu'il atteint un point sûr, conserve ce qu'il a déjà fait, puis reprend avec ton message comme correction.

À utiliser quand : tu viens de repérer une erreur ou tu veux changer rapidement la priorité.

Message → interruption contrôlée → contexte déjà produit conservé → nouvelle génération.

RESPECTER L'ORDRE

Queue

Le message est placé dans une file d'attente. Le modèle termine complètement le tour actuel, puis commence un nouveau tour avec le message en attente.

À utiliser quand : la demande actuelle doit aller jusqu'au bout et la suivante est indépendante.

Message → file FIFO → tour actuel terminé → nouveau tour.

AJUSTER SANS REPARTIR

Steering

Le message est injecté dans le tour en cours, sans créer un nouveau tour et sans interrompre le modèle. Dans Hermes, il arrive à la prochaine frontière de résultat d'outil.

À utiliser quand : tu veux préciser la direction sans perdre le travail déjà engagé.

Message → injection → prochain résultat d'outil → même tour continue.

ABANDONNER

Arrêt

L'arrêt est différent d'une simple interruption : il demande de ne pas poursuivre le tour. C'est le bouton à choisir pour annuler une opération devenue inutile ou bloquée.

À utiliser quand : tu ne veux ni résultat actuel ni nouveau tour automatique.

Commande d'arrêt → annulation/arrêt du travail → session redevient disponible.

CAS PARTICULIER

Approbation

Un message comme « oui » ou « non » n'est pas toujours une nouvelle question. Si le modèle attend l'autorisation d'exécuter une commande sensible, la réponse est routée directement vers le mécanisme d'approbation.

À retenir : le système doit examiner le contexte avant d'appliquer queue, interruption ou steering.

Demande d'autorisation en attente → oui/non → approbation ou refus → tour reprend.

Comment choisir ?

Corriger maintenant : interruption. Attendre sans mélanger : queue. Préciser la trajectoire : steering. Tout abandonner : arrêt. Répondre à une question de sécurité : approbation. En pratique, un vrai gateway doit aussi gérer les images, les outils déjà en cours et les messages de contrôle comme /stop séparément.
