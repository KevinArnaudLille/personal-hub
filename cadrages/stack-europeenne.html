CA2 · ARCHITECTURE, COÛTS ET PÉRIMÈTRE

Stack web européenne. cadrage-stack-europeenne

Une stack managée européenne pour rester concentré sur le produit : frontend Vue/Nuxt, backend Java Spring Boot, service IA Python, PostgreSQL et identité OIDC.

RECOMMANDATION

Option 1 · Clever Cloud + ZITADEL · ~18,80 €/mois

Choix recommandé pour la V1. Clever Cloud fournit le runtime managé, PostgreSQL, les sauvegardes quotidiennes, les métriques et les logs. ZITADEL fournit l'identité OIDC/OAuth2 et le MFA sans gestion maison des mots de passe. Les deux services peuvent être configurés en région européenne ; le DPA, les sous-traitants et la région exacte restent à valider contractuellement.

Le frontend Nuxt peut être compilé puis servi par l'application Java afin de ne pas ajouter un troisième runtime. Le service Python IA reste séparé, avec une instance nano au départ. Les tâches planifiées côté serveur sont possibles via un scheduler applicatif ou un job dédié ; elles ne nécessitent pas forcément une architecture asynchrone avec file de messages.

Cette estimation est un ordre de grandeur hors TVA, domaine et éventuels appels à un fournisseur de modèles IA : 2 runtimes nano à 6 €/mois + PostgreSQL XXS à environ 6,80 €/mois + ZITADEL Free à 0 €. Le nano peut être trop juste pour Java et Python simultanément ; passer à l'option 2 si les tests de charge ou la mémoire le montrent.

COMPARATIF DES COÛTS

  • Option 1 · Lean managée — ~18,80 €/mois : Clever Cloud, 1 runtime Java/Nuxt nano (6 €), 1 runtime Python nano (6 €), PostgreSQL XXS (≈6,80 €), ZITADEL Free, stockage de fichiers non inclus par défaut. Marge d'environ 1,20 € sur le budget de 20 €.
  • Option 2 · Confort managé — ~38,80 €/mois : même architecture, mais deux runtimes XS à 16 € chacun et PostgreSQL à ≈6,80 €. Plus réaliste pour Spring Boot + Python disponibles 24/7, sans changer le modèle d'exploitation.
  • Option 3 · Scaleway composable — ~17,94 €/mois avant stockage et trafic : une instance DEV1-S à 0,00898 €/h (≈6,55 €/mois) pour les services conteneurisés, PostgreSQL DB-DEV-S à 0,0156 €/h (≈11,39 €/mois), Secret Manager et stockage objet facturés à l'usage. Les données restent en régions européennes. Ce choix respecte le budget mais demande davantage de configuration réseau, déploiement, supervision et durcissement de la VM.
  • Option 4 · OVHcloud managé — hors budget : PostgreSQL Discovery est managé, mais le tarif public affiché commence autour de 0,23 €/h par nœud, soit environ 169 €/mois avant le runtime applicatif. À réserver à un besoin de service managé plus robuste, pas à cette V1.

Calculs mensuels sur 730 heures. Les prix fournisseurs évoluent, sont hors TVA et peuvent dépendre de la région, du stockage, du trafic et du taux de change. Aucun coût de modèle IA n'est inclus : il dépend du modèle, des tokens et du fournisseur choisi.

SÉCURITÉ PRISE EN CHARGE ET RESPONSABILITÉS

  • Provider : HTTPS, isolation du runtime, patching de la plateforme, PostgreSQL managé, sauvegardes, métriques et logs.
  • Identité : ZITADEL en OIDC, MFA activé, rôles applicatifs séparés des administrateurs, aucune base de mots de passe dans l'application.
  • Projet : PR obligatoires, Dependabot, SAST léger, secret scan, images ou artefacts immuables, environnements staging/production protégés et approbation avant production.
  • Données : région UE explicitement choisie, chiffrement en transit et au repos, utilisateur PostgreSQL à privilèges minimaux, migrations versionnées et test de restauration.
  • Fichiers : stockage objet européen uniquement si nécessaire, URLs signées, quotas, contrôle du type et de la taille, antivirus si des fichiers non fiables sont acceptés.
  • À notre charge : vulnérabilités du code, dépendances, autorisations métier, journal d'audit, sauvegarde des secrets, revue du DPA et exercice de restauration.

DÉCISIONS ET HYPOTHÈSES

  • Maximum d'environ dix utilisateurs, principalement un seul ; pas d'email transactionnel ni de paiement.
  • Disponibilité 24/7, mais pas d'exigence forte de RTO/RPO : sauvegardes quotidiennes et restauration testée suffisent pour la V1.
  • Le besoin de fichiers reste optionnel. Les tâches planifiées sont probables ; les traitements longs pourront évoluer vers une file de messages plus tard.
  • Le fournisseur et les données doivent être européens. « Région UE » et « fournisseur sous droit européen » sont deux critères à vérifier séparément.
  • Le budget cible est de 20 €/mois ; il est compatible avec l'option 1 seulement avec des ressources minimales et sans coût de modèle IA.

PROCHAINES QUESTIONS

  1. Le service IA appelle-t-il une API externe ou doit-il exécuter un modèle local ? Ce choix domine le coût et la mémoire.
  2. Le dépôt sera-t-il public ou privé ? GitHub Free inclut les Actions dans les dépôts publics ; les minutes privées ont un quota mensuel.
  3. Quelle quantité et quelle sensibilité de fichiers faut-il stocker ?
  4. Faut-il une séparation staging/production permanente, ou un environnement de démonstration suffit-il ?
  5. Le budget de 20 € est-il strict hors TVA, ou peut-il monter à environ 40 € pour éviter les limites mémoire ?
